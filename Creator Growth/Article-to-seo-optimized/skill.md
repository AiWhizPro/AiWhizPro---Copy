# Article → SEO Optimized Version Skill

## Purpose

Convert existing articles into SEO-optimized content that improves discoverability, search rankings, user engagement, and organic traffic potential.

## When To Use

Use when the user requests:

* SEO optimization
* Article optimization
* Search engine optimization
* Organic traffic improvement
* Blog SEO enhancement
* Existing content refresh

## Supported Inputs

* Blog posts
* Tutorials
* Landing page content
* Long-form guides
* Resource articles
* Industry content

## Processing Steps

1. Analyze article.
2. Determine search intent.
3. Evaluate content structure.
4. Improve title.
5. Optimize headings.
6. Improve readability.
7. Add FAQ opportunities.
8. Create meta description.
9. Generate optimized version.

## Output Requirements

### SEO Assets

Generate:

✓ SEO Title

✓ Meta Description

✓ URL Slug

✓ Heading Structure

✓ FAQ Section

✓ Optimized Article

### Content Structure

Recommended:

* H1 title
* Multiple H2 sections
* Relevant H3 subsections
* FAQ section
* Conclusion

### Readability Guidelines

Use:

* Short paragraphs
* Lists
* Examples
* Clear formatting

Avoid:

* Walls of text
* Unnecessary jargon
* Repetitive keywords

### Search Intent Alignment

Match content to:

* Informational searches
* Commercial research
* Problem-solving queries
* Educational queries

### SEO Best Practices

Include:

* Natural keyword placement
* Topic coverage
* Related questions
* User-focused content

Avoid:

* Keyword stuffing
* Manipulative SEO tactics
* Low-value filler content

## Success Example

Input:

A 1,500-word article about email marketing.

Output:

An SEO-enhanced version including:

* Optimized title
* Meta description
* Better heading structure
* FAQ section
* Improved readability

## Success Criteria

The optimized article should rank better for relevant search queries while remaining useful, engaging, and valuable to human readers.

The final content should satisfy both search engines and users without sacrificing quality.
