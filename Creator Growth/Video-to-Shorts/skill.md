# Video → Shorts Skill

## Purpose

Convert long-form videos into multiple short-form content assets suitable for YouTube Shorts, Instagram Reels, TikTok, LinkedIn Video, and Facebook Reels.

## When To Use

Use when the user requests:

* Video to Shorts
* YouTube video repurposing
* Webinar to clips
* Podcast clips
* Reels generation
* TikTok content generation
* Short-form content extraction

## Supported Inputs

* Video transcripts
* YouTube transcripts
* Podcast recordings
* Webinar recordings
* Interview transcripts
* Educational videos

## Processing Steps

1. Analyze transcript.
2. Identify high-value moments.
3. Extract short-form opportunities.
4. Generate hooks.
5. Create short scripts.
6. Recommend duration.
7. Recommend platforms.
8. Generate CTAs.

## Output Requirements

### Number of Shorts

Default:

* 5–10 short-form opportunities

Optional:

* 20+ clips for large transcripts

### For Each Short Include

✓ Title

✓ Hook

✓ Core Message

✓ Script Outline

✓ Duration

✓ Platform Recommendation

✓ CTA

### Platform Optimization

YouTube Shorts:

* Educational
* Search-friendly

TikTok:

* Fast-paced
* Curiosity-driven

Instagram Reels:

* Story-driven
* Shareable

LinkedIn Video:

* Professional insights
* Thought leadership

### Hook Requirements

Hooks should create:

* Curiosity
* Surprise
* Urgency
* Emotional response

Avoid:

* Generic introductions
* Long context
* Weak openings

## Success Example

Input:

A 30-minute YouTube video about creator monetization.

Output:

10 short-form video opportunities including:

* Growth mistakes
* Revenue frameworks
* Monetization lessons
* Contrarian opinions

## Success Criteria

Each generated short should be capable of standing alone while delivering immediate value and encouraging audience engagement.

The output should maximize the amount of reusable content extracted from the original video.
