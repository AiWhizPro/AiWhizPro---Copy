# Blog → Twitter Thread Skill

## Purpose

Convert long-form blog content into Twitter/X threads optimized for engagement, reach, and audience growth.

## When To Use

Use when the user requests:

* Blog to Twitter thread
* Blog to X thread
* Article to Twitter content
* Long-form content repurposing
* Social media thread generation

## Input

Any blog article, including:

* Educational content
* Case studies
* Tutorials
* Opinion pieces
* Industry insights

## Processing Steps

1. Read article.
2. Identify core message.
3. Extract strongest insights.
4. Create curiosity-driven hook.
5. Split content into logical tweets.
6. Ensure smooth progression.
7. Generate CTA tweet.

## Output Requirements

### Thread Length

Target:

* 5–12 tweets

Acceptable:

* 3–20 tweets

### Tweet Guidelines

Each tweet should:

* Communicate one primary idea
* Be concise
* Encourage continued reading

### Hook Requirements

The first tweet should:

* Create curiosity
* Highlight a benefit
* Encourage thread expansion

### Closing Tweet

Include:

* Summary
* Follow CTA
* Engagement CTA when appropriate

## Style

Preferred:

* Conversational
* Insight-driven
* Direct
* Creator-focused

Avoid:

* Corporate language
* Blog-style paragraphs
* Excessive hashtags
* Keyword stuffing

## Success Example

Input:

"10 lessons from growing a newsletter to 50,000 subscribers."

Output:

A 10-tweet thread containing:

* Curiosity hook
* Numbered lessons
* Key takeaways
* Final CTA

## Success Criteria

The final output should feel like a native Twitter/X thread rather than a copied blog article.

The reader should be motivated to continue reading until the final tweet.
