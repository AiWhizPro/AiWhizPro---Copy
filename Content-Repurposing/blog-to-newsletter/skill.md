# Blog → Newsletter Skill

## Purpose

Convert blog content into subscriber-friendly newsletters that improve engagement, retention, and email performance.

## When To Use

Use when the user requests:

* Blog to newsletter
* Article to email newsletter
* Content repurposing for email
* Subscriber content creation
* Weekly newsletter creation

## Input

Any blog article including:

* Educational content
* Tutorials
* Case studies
* Industry analysis
* Thought leadership content

## Processing Steps

1. Read article.
2. Identify primary insight.
3. Extract supporting lessons.
4. Create newsletter angle.
5. Write engaging introduction.
6. Organize content for email readers.
7. Generate subject lines.
8. Add CTA.

## Output Requirements

### Subject Lines

Generate:

* 3 subject line options

Requirements:

* Under 60 characters preferred
* Curiosity-driven
* Benefit-focused

### Newsletter Length

Preferred:

* 300–800 words

Maximum:

* 1,500 words

### Include

✓ Subject lines

✓ Introduction

✓ Main insight

✓ Supporting lessons

✓ Key takeaways

✓ CTA

✓ Sign-off

### Style

Preferred:

* Personal
* Conversational
* Helpful
* Creator-focused

Avoid:

* Academic writing
* Corporate tone
* SEO language
* Large text blocks

## Success Example

Input:

"How I grew my newsletter from 0 to 10,000 subscribers."

Output:

A newsletter containing:

* Subject line options
* Personal introduction
* Growth lessons
* Actionable takeaways
* Closing CTA

## Success Criteria

The resulting newsletter should feel like it was written specifically for subscribers and not copied directly from a blog article.

Readers should gain value even if they never read the original blog post.
