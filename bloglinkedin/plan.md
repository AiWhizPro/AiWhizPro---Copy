# Blog to LinkedIn Project Plan

## Goal
Build a Django-based Blog-to-LinkedIn converter web application using Django templates and Tailwind CDN.

## Tasks

- [ ] Create `blog_to_linkedin` Django app inside `bloglinkedin`
- [ ] Add app to `INSTALLED_APPS` and include URLs in project routing
- [ ] Configure SQLite database and media file handling
- [ ] Define models for conversions, related links, FAQ, features, and workflow steps
- [ ] Register models in Django admin for management
- [ ] Create a conversion form with text paste + file upload support
- [ ] Implement file parsing for `.txt`, `.md`, and `.docx`
- [ ] Implement rule-based LinkedIn post generation logic
- [ ] Build templates with Tailwind CDN and structured app UI
- [ ] Add page sections: Tool Hero, Upload Area, Tool Instructions, Features, How It Works, FAQ, Related Tools, Related Blogs, Share This Tool, CTA, Footer
- [ ] Create a home view to display the converter and saved results
- [ ] Test the app in development

## Notes
- Use built-in Django admin for content and conversion management
- Keep the app modular and maintainable
- Prepare the converter to support future AI API integration
