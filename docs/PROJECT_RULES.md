# Project Rules

Website Type:
Multi-tool SaaS Platform

Examples:

* iLovePDF
* TinyWow

Stack:

Frontend:

* HTML5
* CSS3
* Vanilla JavaScript

Backend:

* FastAPI

Deployment:

* Docker
* Coolify

Rules:

1. Every tool uses same layout.
2. Every tool uses same navbar.
3. Every tool uses same footer.
4. Every tool uses same design system.
5. Mobile-first design.
6. SEO optimized.
7. Accessibility compliant.
8. New tools must not create new styling.
9. New tools must use existing components.
10. Reuse CSS variables only.
