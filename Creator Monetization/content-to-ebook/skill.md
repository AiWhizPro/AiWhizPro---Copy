# Content → Ebook Skill

## Purpose

Transform content assets into ebooks that can be used for lead generation, authority building, audience growth, digital product sales, or educational purposes.

## When To Use

Use when the user requests:

* Ebook creation
* Book creation
* Content compilation
* Authority-building assets
* Lead-generation ebooks
* Digital products
* Educational guides

## Supported Inputs

* Blog archives
* Newsletter collections
* Course materials
* Podcast transcripts
* YouTube content
* Research notes
* Knowledge bases
* Documentation

## Processing Steps

1. Analyze all source content.
2. Identify primary themes.
3. Create book positioning.
4. Design table of contents.
5. Organize chapters.
6. Create chapter objectives.
7. Generate summaries.
8. Create conclusion.
9. Recommend bonus resources.

## Output Requirements

### Generate

✓ Book Title

✓ Subtitle

✓ Target Audience

✓ Book Description

✓ Table of Contents

✓ Chapters

✓ Chapter Objectives

✓ Chapter Summaries

✓ Conclusion

✓ Bonus Resources

### Ebook Structure

Recommended:

* Introduction
* 5–15 Chapters
* Conclusion
* Resources Section

### Chapter Requirements

Each chapter should contain:

* Objective
* Topics Covered
* Key Lessons
* Action Items
* Summary

### Positioning Requirements

Clearly define:

* Target audience
* Problem solved
* Desired transformation
* Reader outcome

### Monetization Opportunities

When applicable suggest:

* Lead magnet upgrade path
* Course upsell opportunities
* Coaching opportunities
* Consulting opportunities
* Membership opportunities

### Writing Style

Preferred:

* Educational
* Practical
* Professional
* Reader-focused

Avoid:

* Blog-style fragmentation
* Repetition
* Platform-specific references
* Excessive promotional content

## Success Example

Input:

100 blog posts about creator growth and monetization.

Output:

Ebook:

"The Creator Growth Blueprint"

Containing:

* 12 chapters
* Frameworks
* Case studies
* Action plans
* Resource section

## Success Criteria

The resulting ebook should feel like a professionally planned book rather than a collection of disconnected content pieces.

Readers should experience a clear progression from problem awareness to practical implementation and transformation.
