# Content → Course Outline Skill

## Purpose

Transform content assets into structured educational products that can be sold, licensed, taught, or delivered as online training programs.

## When To Use

Use when the user requests:

* Course creation
* Curriculum design
* Educational content structuring
* Training program creation
* Learning pathway development
* Content monetization through courses

## Supported Inputs

* Blog collections
* Newsletters
* YouTube content
* Podcasts
* Documentation
* Knowledge bases
* Existing educational materials

## Processing Steps

1. Analyze source content.
2. Identify major concepts.
3. Create learning sequence.
4. Define learning outcomes.
5. Build modules.
6. Create lesson hierarchy.
7. Add assessments.
8. Generate completion outcomes.

## Output Requirements

### Generate

✓ Course Title

✓ Course Subtitle

✓ Course Description

✓ Target Audience

✓ Learning Outcomes

✓ Modules

✓ Lessons

✓ Assessments

✓ Course Completion Outcome

### Learning Path Design

Recommended structure:

* Foundation Module
* Core Skills Module
* Application Module
* Advanced Module
* Implementation Module

### Learning Outcomes

Each outcome should be:

* Specific
* Measurable
* Practical
* Outcome-oriented

### Assessments

Include:

* Knowledge checks
* Practical assignments
* Projects
* Reflection exercises

### Course Positioning

Clearly define:

* Who the course is for
* What problem it solves
* What transformation it delivers

## Success Example

Input:

A collection of 50 blog posts about creator monetization.

Output:

Course:

"Creator Monetization Mastery"

Containing:

* 6 modules
* 32 lessons
* Projects
* Worksheets
* Final implementation plan

## Success Criteria

The resulting outline should be detailed enough for a course creator to immediately begin recording lessons or developing learning materials.

The course should provide a complete learning journey from beginner understanding to practical implementation.
